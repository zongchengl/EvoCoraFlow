# EvoCoraFlow
EvoCoraFlow 是一套语音驱动的微流控液滴操控系统，核心为一套可迁移的自适应精英引导优化算法族 AEG（Adaptive Elite-Guided）。视觉上，YOLO 定位液滴与激光，经 HSV 颜色聚类加 EMA 平滑、迟滞匹配、离群过滤三层防抖稳定编号，辅以 ROI×imgsz 尺度标定与 KCF 单目标跟踪；规划上，26×26 网格启发式打分选定落点，AEG-RRT* 以差分精英变异引导 Informed RRT* 采样，在路径长度、安全余量、平滑度多目标下生成等价避障路径档案，按液滴密度实时择一执行；批量任务由 AEG-Batch 双层优化求解，上层变长编码自主决定分批与落点，下层贪心规划批内最短搬运顺序；调优上，AEG-Replay 以轨迹回放离线整定控制增益。
