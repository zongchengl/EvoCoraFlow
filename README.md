# EvoCoraFlow 液滴自动操控与语音交互系统

这是一个保持原目录布局的整理包，包含视觉与执行主链、语音交互链、离线调试链。聊天入口默认不连接设备；主链的图片、USB 和真实设备入口按各自模式采集和控制。先完成离线测试，再按现场设备逐项启用。

## 三条链路

- **装置操控主链**：检测液滴与激光，经过颜色/尺寸分组、EMA 平滑、迟滞匹配和离群过滤稳定编号；单目标移动优先使用 KCF，短时漏检时退化到预测；26×26 网格先找安全落点，再用 AEG-RRT 生成多目标候选路径。
- **语音交互链**：本地语音识别、可配置的兼容对话接口、语音播报和安全桥接。语音界面默认仅聊天，硬件桥接需要在本机显式打开。
- **离线调试链**：无相机、无电机条件下验证编号、指令解析、落点净空、路径候选、批量队列和回放调参。

## 全液滴自动任务

输入“把全部液滴自动分批移到右侧”后，系统把当前画面中的液滴作为任务集合：上层联合搜索变长批次、顺序先验和落点候选序号，下层改善批内顺序并解码安全网格落点，执行器逐项复核身份、净空和路径状态；任一任务无法安全匹配时整批停止并刹车。
